# Política de Privacidade – Free Ads Scanner

**Última atualização:** 11 de maio de 2026  

O aplicativo **Free Ads Scanner** (“Aplicativo”) foi desenvolvido para permitir a digitalização de documentos de forma simples e segura. Esta Política de Privacidade descreve como tratamos as informações dos usuários.

## 1. Informações Coletadas
- **Documentos digitalizados:** O aplicativo processa imagens e documentos apenas localmente no dispositivo. Nenhum arquivo é enviado para servidores externos.  
- **Permissões do dispositivo:**  
  - `android.permission.CAMERA`: necessária para capturar imagens dos documentos.  
  - `android.permission.READ_PHONE_STATE`: utilizada para identificar o estado do dispositivo e garantir funcionamento adequado em diferentes versões do Android.  
  - `android.permission.WRITE_EXTERNAL_STORAGE` / `READ_EXTERNAL_STORAGE`: necessárias para salvar e acessar documentos digitalizados.  

## 2. Uso das Informações
As informações coletadas são utilizadas exclusivamente para:  
- Permitir a digitalização e armazenamento de documentos.  
- Garantir o funcionamento correto do aplicativo em diferentes dispositivos.  
- Melhorar a experiência do usuário.

## 3. Compartilhamento de Dados
- O aplicativo **não compartilha** documentos ou informações pessoais com terceiros.  
- Nenhum dado é transmitido para servidores externos.  

## 4. Segurança
- Todos os documentos permanecem armazenados apenas no dispositivo do usuário.  
- Recomendamos que o usuário utilize senhas ou bloqueio de tela para proteger seus arquivos.  

## 5. Alterações
Podemos atualizar esta Política de Privacidade periodicamente. A versão mais recente estará sempre disponível no nosso repositório oficial no GitHub.
